# SharkPass móvil

App independiente para iOS y Android con Expo SDK 58 y Expo Router. Leer el AGENTS.md de la raíz. Usar npm workspaces y un solo lockfile. Instalar módulos nativos con `npx expo install` desde esta carpeta. Consultar documentación SDK 58 antes de usar APIs. Respetar los SVG y dimensiones de Figma; no dibujar barras de estado falsas. Nunca almacenar contraseñas ni tokens en AsyncStorage. No presentar datos DEMO, pagos o compilaciones para tiendas como reales sin verificarlos. Ejecutar typecheck y exportación iOS/Android/web; registrar pruebas físicas pendientes.
