# SharkPass
Proyecto independiente de Localia. Nombre provisional para Shark Caribe.
Usar Node 22.17.1 y un único package-lock.json. No guardar secretos ni datos personales reales.
No presentar pagos como reales sin una pasarela conectada, firmas verificadas e idempotencia.
Las migraciones aplicadas son inmutables. Añadir otra para cambios de esquema.
Ejecutar npm run check, npm run build y una prueba del contenedor antes de desplegar.
Probar aislamiento entre organizadores, cupos simultáneos y escaneo único.
